# Dony Skill 目录

每个 Skill 是**一个文件夹**，里面放一个 `SKILL.md`：

```
skills/
  daily-report/          ← 文件夹名 = 技能 id（load_skill 用它）
    SKILL.md
```

`SKILL.md` 顶部是一段 `---` 包裹的元信息，正文是给模型看的完整用法说明：

```markdown
---
name: 技能显示名
description: 一句话说明什么时候用（会出现在系统提示词的技能清单里）
---

# 完整用法说明

模型会在需要时用 load_skill 读到这里的全部内容，
再结合 Dony 已有工具（文件/命令/UIA/联网…）执行。
```

要点：

- Skill **只提供知识/方法**，由模型按说明调用已有工具去完成 —— 安全、可分享。
- **没有单独的安装/启用步骤**：读到说明即生效，直接照做即可。
- 放进/删除文件夹后即时生效：`STUDIO设置 → Dony MCP 与 Skill` 的列表立刻可见，
  系统提示词也是每轮请求重扫，**下一轮对话即可用**，无需重启。
- 本目录位置可在设置页修改（`AGENT_SKILLS_DIR`），**改目录需重启 Dony**。
